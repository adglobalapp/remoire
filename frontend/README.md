# Remoire - Frontend

A personal space for your stories, memories, and milestones. Remoire is a modern web application designed to help you capture the rhythm of your life through interactive journals and living timelines.

## ✨ Features

- **Personal Journal**: A digital diary for deep reflections and daily highlights.
- **Living Timelines**: An interactive canvas to see your memories unfold over months and years.
- **Quick Thoughts**: Instant sticky notes for small sparks of inspiration and random ideas.
- **Share the Journey**: Stay connected with your inner circle and share favorite spots/updates.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: TypeScript
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS (CSS Modules)
- **Editor**: [Tiptap](https://tiptap.dev/)

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
